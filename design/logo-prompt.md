# Logo prompt for Deskpouch

Paste into ChatGPT (image generation). Attach a PNG export of `design/mocks/FinalPanel.dc.html` if possible so it sees the real UI.

```
Design a logo and macOS app icon for "Deskpouch".

WHAT IT IS
Deskpouch is a small native macOS menubar app: a pouch of personal capture tools. Hold a key, speak, release, and the transcript is pasted into whatever app you're in (transcription runs locally on the machine). Press a shortcut, pick a region, and it records the screen to a file. More little tools will be added over time. There is no main window, just one floating panel that drops from the menubar icon, and a small floating pill that shows live state. It is a quiet, fast utility you keep in your pocket, not a big creative suite.

NAME AND METAPHOR
"Pouch" is the core idea: a small, soft container that holds a few well-made tools. The current menubar glyph is a simple line-drawn bag (trapezoid body, rounded handle on top). Evolve that idea, don't copy it. Possible directions: a pouch with a drawstring, a pouch whose opening doubles as a microphone capsule or a record dot, a pouch built from vertical audio meter bars. Avoid a literal Mac desk, keyboard, or generic "AI sparkle" cliches.

VISUAL SYSTEM (match the app exactly)
- Ground: mint-tinted near-black. Base #0d1211, panel gradient #1a2320 to #121a17. Hairlines and subtle fills are mint rgb(180,255,220) at very low opacity.
- Accent: warm amber #f59e0b, with highlight #fbbf24 and shadow #d97706. Anything drawn on amber uses dark ink #1c1917, never white.
- Text/cream: #e8f5ef.
- Secondary status colours, use sparingly: mint #2dd4a3 (ok), coral pink #fb7185 (recording).
- Typography if a wordmark is included: Geist (a geometric grotesque), semibold, tight tracking. No serif, no monospace, no script.

FEEL
Polished, modern, slightly premium, dark. Physical and tactile rather than flat: the UI uses keycap-style buttons with a solid bottom shadow, soft amber glows around active elements, and 3px fully rounded vertical meter bars for audio. Think a well-made leather pouch photographed under a warm lamp, translated into a crisp vector mark. Deliberate and calm, not playful or cartoonish. Not a generic macOS system icon. It should stand out in a menubar row of grey glyphs.

DELIVERABLES
1. Primary mark: an amber pouch on the mint-black ground, in the macOS 26 squircle app-icon shape, with subtle inner highlight along the top edge and a soft amber glow beneath the mark.
2. Monochrome glyph version: single colour, line-based, must survive at 16 x 16 px in a menubar (thick enough strokes, no fine detail).
3. Horizontal lockup: mark plus "Deskpouch" wordmark in Geist Semibold, cream text on the dark ground.
Show all three on one sheet, plus the app icon alone at large size. Vector-style rendering, no photo textures, no mockup devices, no text other than the wordmark.
```
